Foliome

Un site de portfolio dessiné sur mesure, que vous mettez à jour vous-même.


Cette page se modifie comme votre site : cliquez sur un élément, un panneau s’ouvre juste à côté.

Votre site change quand vous le décidez.

  1. Il est créé pour vous

    Je le dessine et je le code sur mesure, avec ses animations et son caractère. Rien ne sort d’un modèle.

  2. Vous le modifiez de chez vous

    Ouvrez-le avec votre code d’accès, sur ordinateur ou sur téléphone, sans rien installer. Cliquez sur un texte, une image, une couleur.

  3. Vous le mettez en ligne

    Un bouton, et vos visiteurs voient la nouvelle version. Vous n’avez personne à prévenir.

Foliome s’occupe du reste.

Vos photos
Envoyez-les telles quelles, même depuis votre téléphone. Elles sont redressées, allégées, et leur position GPS est retirée.
Tous vos fichiers
PDF, sons, modèles 3D, archives : tous les formats sont acceptés.
Vos retours en arrière
Annulez jusqu’à cent modifications, si le résultat ne vous plaît pas.
Vos langues
Un onglet par langue, à côté de chaque texte à traduire.

Un projet de site ? Écrivez-moi.

Je dessine et je code des sites de portfolio pour des artistes, des architectes et des designers. Foliome est l’outil que j’ai construit pour que vous puissiez ensuite les modifier vous-même.
